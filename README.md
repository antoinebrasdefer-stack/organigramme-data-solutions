# 👥 Organigramme — Data Solutions (Claranet)

Trombinoscope interactif de l'équipe Data Solutions.

## 🌐 Accéder au site

👉 **[Ouvrir l'organigramme](https://antoinebrasdefer-stack.github.io/organigramme-data-solutions/)**

---

## 📋 Fonctionnalités

- **Trombinoscope** : vue en grille avec recherche et filtres
- **Diagramme de Venn** : répartition visuelle Interne / Externe / Les deux
- **Fiche détaillée** : parcours, mission, compétences, passions, ancienneté
- **Recherche** par nom, rôle ou compétence
- **Filtres** par compétence et type de mission

## 🔄 Mettre à jour les données

1. Modifie le fichier **`equipe.xlsx`** (OneDrive)
2. Lance le convertisseur **`convertir.html`**
3. Copie le JSON généré
4. Remplace le contenu de **`data.json`** sur GitHub
5. Le site se met à jour automatiquement ✅
